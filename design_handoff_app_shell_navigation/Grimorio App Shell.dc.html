Spec 004 · feature/004-app-shell-navigation

Grimorio — app shell

Top bar, área de sincronização, indicador de perfil, menu lateral (recolhido / expandido / fixado), gaveta no celular e aviso legal. Tudo com tokens e primitivas existentes (.btn*, .grm-wordmark, MiniWheel, ProfileRow, receitas de luz). O conteúdo das páginas é placeholder — fora do escopo. O modal de perfil é uma versão resumida só para demonstrar os fluxos de abertura.

Estilo “Fio de luz” (Nav Options 1c + top bar 4b): a hairline da top bar é uma faixa nas cores do perfil que flui devagar, dobra a esquina e desce pela borda esquerda como um fio de 1px; cada destino é uma conta no fio, e a atual acende. O wordmark e o rótulo atual são pintados pela mesma faixa. Sincronização + perfil formam uma placa única. Nenhum glifo novo — o botão de menu diz Menu. A sincronização não usa cores de sucesso/aviso (ainda indefinidas): só role-accent e danger, com marcas de formas diferentes. Faixas: ≥ 960 px menu lateral; < 960 px gaveta; ≤ 640 px formas compactas na top bar.

Nenhuma cor nova. Sucesso/aviso continuam indefinidos: estados saudáveis usam text/muted, falhas usam --color-danger.

Layout e rolagem

Raiz: grid auto | minmax(0,1fr), height: 100dvh, overflow: hidden em html/body. A área de vista (<main>) é a única região que rola; é uma coluna flex para o aviso ficar embaixo com margin-top: auto. scrollTop = 0 a cada troca de rota. Padding da vista: space-6 (space-4 ≤ 640).

Nome de perfil: 3 a 16 caracteres. Helper “3 a 16 caracteres: letras, números, _ . ou -”; erro “Use de 3 a 16 caracteres.”

App top bar (substitui a entrada atual)

Página, padding 4px × space-4 (space-2 ≤ 640); embaixo, --line-band fluindo; à esquerda, --wash-band. Wordmark pintado por --band-lit. Ordem: Menu (só < 960) · wordmark 1.25rem (link para Início, alvo 44px, hover → --role-primary-hover, sem sublinhado) · à direita, gap space-2 (space-1 ≤ 640): área de sincronização e indicador de perfil.

Botão Menu: .btn--ghost, “Menu” em eyebrow (0.75, 0.14em, maiúsculas, muted), aria-expanded, aria-controls. Nenhum glifo novo.

Sync + perfil: só texto, sem face nem borda — dois alvos de 44px separados por um divisor vertical de 1px × 20px (border). Hover: sync → text; perfil → role-primary-hover. Perfil: pontos 8px + nome (Karla 700, 0.875); a tribo fica no aria-label/title. Sem perfil: “Entrar” em texto 700. Compacto: pontos --pip-compact sobre o nome (0.75, 700) — nunca trunca. Sem perfil: .btn--secondary “Entrar”, sem cores do perfil. Durante sincronização: aria-disabled (opacidade .5, not-allowed), título e rótulo “Aguarde a sincronização terminar”.

Área de sincronização: Largo: marca + texto 0.75 em linha. Compacto: marca sobre texto 0.75 (coluna, padding space-1). O texto completo fica em aria-label/title. Ver os estados em 4.

Marcas de estado (8px)

Estados saudáveis são neutros — a cor fica só para erro: spinner muted = sincronizando · ponto text + brilho = sincronizado · ponto muted = há N min · anel 1px text = nunca · anel 1px muted = sem conta na nuvem · ponto danger + glow = sem conexão / sessão expirada / falha (texto e ação também em danger). Assim uma identidade vermelha (Boros, Izzet…) nunca parece erro. Forma e texto diferem sempre — nunca só a cor.

Menu lateral

Recolhido: 24px, sem borda. Fio de 1px em left: 11px com --band-v fluindo (grm-flow-v 120s) e brilho 0 0 6px primary 35%; lavagem da faixa a 20% no topo. Cada destino = conta de 7px (página + hairline). Toque no fio fixa.

Atual: conta cheia em role-primary com 0 0 0 3px bg, 0 0 10px 1px primary; aberto, o rótulo fica 700 pintado por --band-lit. aria-current="page".

Expandido (hover/foco): 232px sobre o conteúdo, hairline à direita, --shadow-rest + 0 0 24px -6px primary 45%. Um espaçador de 24px segura o layout — a vista não se move. Fecha 120ms após sair.

Fixar: no topo do menu aberto, em estilo eyebrow: “Fixar menu” / “Recolher menu”, aria-pressed. Fixado: espaçador vira 232px, sem sombra. Preferência por aparelho em localStorage.

Gaveta (< 960): --drawer-width, sobre tudo com backdrop 75%. Cabeçalho = top bar (faixa, wordmark pintado, linha fluindo) + ✕; o fio desce pela lista com as contas. Sem pino, sem faixa. Fecha ao escolher, tocar fora, Esc/Voltar; foco preso dentro, volta ao Menu. Entra deslizando em --duration-base; parado com reduced motion.

Aviso legal

Fim da vista, hairline acima, padding space-5 × space-6, 0.75rem muted, parágrafos com max-width: 72ch. Links role-accent, target="_blank"; alvo de 44px por padding vertical com margem negativa (não altera a entrelinha). Texto vem de uma fonte única compartilhada com Sobre.
