# grimorio

Projeto Angular 22 em estado inicial — uma única rota exibindo "Hello World".

O contexto e o histórico da versão anterior (proposta, especificações, modelo de dados,
histórico de uso de IA) estão preservados em [`backlog/VibeCoding/`](backlog/VibeCoding/).

## Desenvolvimento

```bash
npm install
npm start      # servidor de desenvolvimento em http://localhost:4200
npm run build  # build de produção
```
